Login / เปลี่ยนบทบาท · หน้าแรก

1 · Customer: ซื้อ campaign สำหรับจอนี้

2 · Campaign / cache

Prefetch ดาวน์โหลดไฟล์ครบ ตรวจ SHA-256 แล้วเก็บใน Cache Storage ของ browser จอนี้ จากนั้นเล่นผ่าน Blob URL ไม่ stream ตอนเล่น · ต้อง Prefetch ใหม่ถ้าเปลี่ยน browser

3 · Operator: ตรวจพบ target → ประมูล

Exact match / any → cache พร้อม → งบพอ → bid สูงสุด; ราคาเท่ากันใช้ campaign ID ต่ำกว่า · หนึ่ง queued/playing slot เท่านั้น



4 · เล่นและบันทึกผล
เล่นจบจึงลง charge; เล่นผิดพลาดให้ยกเลิก ไม่คิดเงิน ภาพกล้องและ attention ยังไม่เชื่อม


5 · Reviewer: ตรวจบิลย้อนหลัง
เหตุผลและ charge/refund คงประวัติ ไม่ลบยอดเดิม รายการซ้ำไม่คิดเงินซ้ำ
