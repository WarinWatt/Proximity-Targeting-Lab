OPENPAR · PROMPTPAR / PA100K

เห็นคุณลักษณะอะไรบ้าง?

รับภาพคนเดียวจาก webcam → วิเคราะห์คุณลักษณะขั้นต้น → ยังไม่สรุป segment

เลือก webcam หรือคลิปที่มีสิทธิ์ใช้งาน · คลิปเล่นใน browser ไม่อัปโหลดทั้งไฟล์ ส่งเฉพาะภาพในกรอบเมื่อกด “วิเคราะห์ภาพนี้” ไปบริการบนเครื่องนี้ ไม่มีการบันทึกภาพหรือส่งเข้า cloud

อัปโหลดคลิปจากเครื่อง

เลือกไฟล์แล้วใช้ปุ่มเล่นและแถบเวลาในช่องวิดีโอด้านล่าง กด “วิเคราะห์ภาพนี้” เพื่อหยุดและวิเคราะห์เฟรมนั้น · ต้องมีคนเดียวในกรอบกลาง ยังไม่ตรวจหาคนหลายคนอัตโนมัติ · เปลี่ยนแหล่งภาพจะล้างผลเดิม ปุ่ม “ปิดกล้อง / ล้างผล” ใช้ปิดคลิปได้ด้วย

1 / กล้องและกรอบคน

ยังไม่เปิดกล้อง

ยืนคนเดียวให้เห็นศีรษะถึงเท้าในกรอบกลาง · กรอบกำหนดเอง ไม่ใช่ผลตรวจหาคน · ไม่เชื่อมตัวตนข้ามกล้อง

2 / ผลคุณลักษณะจากภาพที่ส่ง

กำลังตรวจบริการโมเดลบนเครื่อง…

ยังไม่มีผล — ไม่เติมคะแนนจำลอง

≥ เกณฑ์: พบ · ≤ 1−เกณฑ์: ไม่พบ · ระหว่างนั้น: ไม่แน่ใจ · เป็นกติกาสำรวจ ไม่ใช่ threshold ที่ผ่านการ validate

ขอบเขตของแท็บนี้

PromptPAR checkpoint PA100K ให้ 26 คุณลักษณะ เช่น ช่วงอายุ ทิศทางลำตัว เสื้อผ้า และสิ่งที่ถือ คะแนน sigmoid เป็น output ของโมเดล ยังไม่ใช่ความน่าจะเป็นที่ปรับเทียบแล้ว และอาจผิดเมื่อภาพไม่ชัดหรือเห็นคนไม่ครบ

label เพศ/อายุเป็นการประมาณจากรูปลักษณ์ตามชุดข้อมูล ไม่ยืนยันอัตลักษณ์หรืออายุจริง ไม่ตรวจครอบครัว พี่น้อง เพื่อน หรือคนรัก ไม่มีการประมูลหรือคิดเงินในแท็บนี้

OpenPAR / PromptPAR ต้นฉบับและ checkpoint · เหตุผลที่แยก attributes ออกจาก segment

Webcam ต้องใช้ localhost หรือ HTTPS · บริการ inference ฟังที่ 127.0.0.1:8042 เท่านั้น หน้า warin.me ออนไลน์ยังไม่ได้เชื่อมบริการนี้

บันทึก / Attributes ก่อนรวมเป็น segment

ตารางด้านบนแสดงครบ 26 attributes ตั้งแต่ก่อนเปิดกล้อง คะแนน “—” หมายถึงยังไม่ได้วิเคราะห์ ไม่ใช่คะแนนศูนย์ เมื่อโมเดลพร้อม ให้เปิด webcam → ยืนคนเดียวในกรอบ → กด “วิเคราะห์ภาพนี้” คะแนนจะปรากฏในตารางเดียวกัน โดยอ้างอิงภาพที่ส่ง ไม่ใช่ภาพสดทุกเฟรม
