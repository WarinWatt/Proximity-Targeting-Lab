# Release verification: 15 November 2026

Deployed to https://warin.me/pages/content-decision-lab/ using the existing warin_web Apache / warin_db MariaDB deployment.

## Delivered

- Shared shell on 11 pages with role navigation, simulation/pilot labels, mobile menu and per-page evidence reports.
- Ten advanced simulation scenarios; reservations include the maximum engagement premium and expose budget snapshots.
- Persistent pilot supports five stations, shared campaign budget locks, payload-bound idempotency, append-only charges/refunds and retrospective review.
- Owner dashboard shows ledger totals, reserved budgets and pending reviews. Health endpoint proves DB reachability; device heartbeat remains unknown.
- Attention endpoint and manual form persist append-only, nonbillable simulation measurements linked to completed playback. Duplicate keys are idempotent; conflicting payloads are rejected.
- Public hosts reject demo login. Secure/HTTP-only/SameSite cookies, exact origins, CSRF, host allowlist, request bounds, security headers, session expiry and shared initial session fetching are enabled.
- Four private role accounts provisioned; credentials stored outside document root. No passwords are committed.

## Evidence

- 45 Node unit tests passed.
- Database migrations reapplied and central acceptance/invariant checks passed in isolated release environment.
- Five concurrent station requests admitted only two affordable bids under a two-bid campaign budget; playing holds and cancellation release checked.
- HTTP tests passed purchase, allocation, duplicate completion, attention retry/conflict, refund reconciliation, role restrictions, CSRF/origin/host checks and setup-script denial.
- Browser checks passed all 11 pages on local release and public HTTPS; no JavaScript page errors, single report mount, desktop scenario table and mobile menu checked.
- All four private accounts passed HTTPS login and owner endpoint isolation; public demo login denied.
- Existing site and database backed up before additive migrations and runtime deployment, under private .artifacts/releases/20261115-052122.

## Limits

This release is an internet-accessible research pilot, not approved monetary production. Campaign Sales remains a simulation; persistent purchasing is in the station pilot page. Targets are simulated, browser playback reports are not trusted device attestations, attention is manually entered, and no real payment provider is integrated. OpenPAR inference accuracy, real gaze validity, operational load/power measurements, offline fleet synchronization, annotation workflow and dataset/model lifecycle still require implementation and validation. See DEPLOYMENT.md and FINAL-REPORT-PLAN.md.
